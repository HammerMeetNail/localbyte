# Goodform concept

Goodform is a fictional independent bookkeeping consultant concept for the LocalByte Starter Website tier. The one-page site has five sections: introduction, services, approach, about, and inquiry. Its white and muted blue identity uses conventional heading sizes, plain-language service details, and a compact example of the monthly deliverables. The page explains the service, who it suits, the working process, and how to start an inquiry.

## Route

- `/demos/goodform/` — complete one-page responsive concept
- Navigation links use section anchors. The Starter Website link points to `/pricing.html#single-page`; the discussion link points to `/contact.html?service=single-page`.

## Simulated actions and scope

The inquiry form uses browser validation and then renders a local preview. It does not send a message or retain any entered information. Without JavaScript, its submit button stays disabled and a note explains the local preview requirement. No accounting software connection, tax preparation, regulated advice, client accounts, or professional credentials are claimed. All names and copy are sample content; this is a fictional LocalByte concept.

## Design references

Reviewed [Sound Bookkeepers](https://sbk2.co/) and [Footing Co.](https://footingco.com/) for explicit bookkeeping deliverables, service scope, and a clear consultation path. No source text, prices, reviews, credentials, branding, or imagery were copied. Goodform makes no software certification or regulated-advice claim.

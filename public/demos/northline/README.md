# Northline Studio — Business Website example

Northline Studio is a fictional interiors practice concept. Its visual direction is a quiet architectural portfolio with a narrow studio rail, image-first presentation, restrained editorial type, and a single imagined interior study.

## Pages

- `index.html` — studio overview and link to the featured study
- `services.html` — interior direction, spatial planning, material work, and process
- `work.html` — one coherent imagined case study with detail crops, material swatches, and a schematic plan
- `about.html` — the studio's fictional point of view
- `contact.html` — native-validated local inquiry preview

The Quiet House scene in `assets/img/quiet-house-concept.webp` is an imagined, AI-generated concept image. Its repeated crops describe the same fictional study; it is not a client project, completed work, or measured result. The five pages use responsive HTML, CSS, and vanilla JavaScript. The form previews entered details in the current browser page and does not submit, store, or send them. With JavaScript disabled, the request button remains disabled and the explanatory note stays visible. Main navigation remains available without JavaScript.

Use `/demos/northline/index.html` in the repository's existing preview server; no dependencies or build step are required.
